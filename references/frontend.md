# 前端规则

仅在任务触及页面、交互、浏览器状态、前端接口调用或前端构建时应用。遵循项目现有框架和组件模式，不为统一形式引入新依赖或重构无关代码。

## 对焦与方案

- 明确页面入口、用户角色、显示条件、主路径及失败路径。
- 明确加载、空数据、错误、禁用和重复操作状态。
- 识别路由、权限、公共组件、全局状态和共享样式的影响范围。
- 接口未就绪时区分临时 Mock 与正式契约，并标明替换边界。
- 优先复用现有组件、请求封装、校验和状态模式。

## 实施检查

- 在信任边界校验输入；防止重复提交和过期响应覆盖新状态。
- 保持成功、失败、空数据和加载状态可恢复。
- 公共组件变更保持默认行为兼容，并检查现有调用方。
- 不把密钥、敏感信息或内部错误暴露到客户端和日志。
- 保留键盘操作、可读标签、焦点和基础对比度等可访问性要求。

## 最小验证

- 运行与改动直接相关的静态检查、类型检查或目标测试。
- 在真实浏览器验证主路径和一个关键失败或边界路径。
- 检查控制台错误、失败请求、加载和空数据状态。
- 公共组件、路由或状态变更增加相关回归验证。
- 默认不执行 build/打包；仅构建/发布配置变更或用户明确要求时执行。执行 lint 或 format 前判断命令是否会改写源码、删除产物或触发发布步骤。

使用 `AC-FE-*` 不是强制要求；已有 `AC-*` 足够时不要增加命名层级。
